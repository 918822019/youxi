# 早期原型归档

`godot-strategy/` 是独立的 Godot 4 / C# 战略游戏实验，不参与根目录 README 所述的 React + FastAPI 战役。入口为 `godot-strategy/project.godot`，保留了场景、脚本、项目配置和世界数据；运行需要 Godot 4 的 .NET 版本。

此目录不包含 Godot 的 `.godot/` 导入缓存及 .NET 编译产物。Web 版的开发与构建只需关注仓库根目录的 `frontend/` 和 `backend/`。

仓库初始提交还包含其他与游戏无关的练习目录、IDE 配置和生成文件，已从当前工作树移除；如需查阅历史，可查看 Git 的初始提交 `2641f64`。
