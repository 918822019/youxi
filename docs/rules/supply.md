# 补给与失联

权威逻辑：`Game._supply_network`、`Game._economy`（`backend/core/game.py`）。

## 补给网

一国的**补给网** = 由该国**指挥部**出发，仅经过本国省份、可连通到达的省份集合（BFS，`_supply_network`）。

- 指挥部起始：我方王都、东境东港。
- 指挥部失守后，起点迁移到该国仍控制省份中 `IDS` 顺序最靠前的一个。
- 若该国已无省份，补给网为空。

## 日耗补给

每推进一天，对每支部队：

```text
cost = max(1, (兵力 + 19) // 20) + (若有军令则 +1)
```

- 若部队所在省在补给网内**且**库存 ≥ cost → 扣库存。
- 否则 → 该部队**损失 2 兵力**（最低降到 1），日志「补给不足，损失 2 人」。

也就是说：大军比小队吃得多，行军中额外多耗 1。

## 失联的影响

| 场景 | 后果 |
|---|---|
| 部队所在省不在补给网 | 每日掉 2 兵 |
| 发起进攻时出发省不在补给网 | 进攻被拒绝（`game.py:163`） |
| 城池不属于补给网 | 无法在该城征募 |
| 省份不在补给网 | 其工厂不产出 |
| 守军所在省不在其补给网 | 该守军防御 ×0.6（利于进攻方） |

## 断线与重连

战线变化会改变补给网：某省被敌军切断后，其上的部队与工厂随即失联。恢复连通后自动重新接入。
