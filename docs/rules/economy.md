# 经济与生产

权威逻辑：`Game._apply`、`Game._economy`（`backend/core/game.py`）；常量见 `backend/core/world.py`。

## 每日收入

每推进一天：

- **金**：`+ 拥有的省份数`。
- **工厂产出**：仅统计**接入补给网**的己方省份，产出 `工厂总数 × 2`，投入当前生产项
  - 生产倾向为**装备** → 装备 `+ 工厂×2`
  - 生产倾向为**补给** → 补给 `+ 工厂×2`

只有连到指挥部的省份才提供工厂产出；失联省份既不产出也不产金逻辑上仍计入金（金按省份数计）。

## 生产倾向

- 通过 `set_production` 在**装备 / 补给**之间切换，立即生效。
- 初始双方均倾向装备。

## 征募

| 项目 | 数值 |
|---|---|
| 花费 | 20 金 + 10 装备 |
| 效果 | 兵力 +10 |
| 条件 | 城池属于你，且该城接入补给网 |

- 若该城已有**待命**（无军令）部队，则其兵力 +10。
- 否则新建一支「第 N 后备军」（兵力 10）。
- 指定 `unitId` 时必须为该城待命部队，否则拒绝。
- 资源不足时拒绝：「需要 20 金与 10 装备」。

## 金 / 装备 / 补给一览

| 资源 | 来源 | 用途 |
|---|---|---|
| 金 | 每天 = 拥有省份数 | 征募 |
| 装备 | 工厂 ×2（生产倾向=装备） | 征募 |
| 补给 | 工厂 ×2（生产倾向=补给） | 维持部队（见[补给](supply.md)） |

## 胜利条件

当九省只剩**一个归属**（一方占领全部省份）时判定胜利，后续命令被拒「对局已结束」。
