# 战斗结算

权威逻辑：`Game._resolve_orders`（`backend/core/game.py:284-315`）。战斗只在部队**抵达敌方省份**时发生一次。

## 判定公式

```text
攻方 attack  = 部队兵力            （若攻方当前所在省不在补给网内，则 ×0.6）
守方 defense = 城池驻军 + Σ 各守军兵力（守军所在省不在其补给网内者，各自 ×0.6）

若 attack > defense → 占领
否则               → 进攻失败
```

!!! warning "严格大于"
    必须是 `attack > defense`。两者相等时判定为**进攻失败**。

## 胜利（占领）

- 攻方损失 `max(1, defense // 2)` 兵力。
- 该省所有守军被歼灭。
- 该省归属改为攻方，驻军重置为 **5**。
- 攻方部队进入该省，继续后续段落。

## 失败

- 攻方损失 `max(2, defense // 4)` 兵力。
- 每个守军损失 `max(1, attack // 6)` 兵力（最低 1）。
- 攻方兵力归 0 则部队被消灭，否则清除军令。
- 日志「XX 进攻 YY 失败，军令终止」。

## 举例：开局为何打不动

| 进攻 | 攻方兵力 | 目标 | 守方 | 结果 |
|---|---|---|---|---|
| 第一军 → 东港 | 30 | `east` | 驻军 8 + 东境军 25 = 33 | 30 < 33 失败 |
| 北方军 → 苍原 | 22 | `northeast` | 驻军 10 + 边境军 18 = 28 | 22 < 28 失败 |

## 提高胜率的做法

- 先用[征募](economy.md)把兵力堆到超过「驻军 + 守军」。
- 打**孤立城池**或**守军已调走**的目标。
- 令守方**失联**（其防御 ×0.6），同时确保自己出发省接入补给网（否则你的攻击 ×0.6）。
- 失败会按防御比例掉兵，连续硬攻只会越打越弱。
